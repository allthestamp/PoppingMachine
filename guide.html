사용방법

팝핑머신은 열이 아닌 빛으로 제작하는 감광 방식입니다. 사용 중인 모델을 선택해 영상과 적층 순서를 확인하세요.

RED MODEL / VIDEO GUIDE가로 영상

레드 모델 사용 순서

  1. 프린터로 도안을 팝핑지에 선명하게 인쇄합니다.
  2. 고무패드 위에 필름을 놓고, 도안(팝핑지)을 가장 위에 올립니다.
  3. 세 재료의 위치를 맞춘 뒤 기계의 작업 공간에 넣습니다.
  4. 감광이 끝나면 고무패드를 꺼내 도안이 고르게 표현됐는지 확인합니다.

레드 모델은 아래에서부터 고무패드 → 필름 → 도안(팝핑지) 순서입니다.

CHECK 01

감광 방식

열로 각인하지 않고 빛을 이용해 도안을 감광합니다.

CHECK 02

예열 불필요

전원을 연결한 뒤 별도 예열 없이 사용할 수 있습니다.

CHECK 03

앞·뒤 구분 없음

필름과 팝핑지는 앞면과 뒷면을 구분하지 않습니다.

CHECK 04

인체에 안전

제작 과정에서 유해 물질이 발생하지 않아 안전하게 사용할 수 있습니다.
